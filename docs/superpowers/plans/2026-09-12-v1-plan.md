# V1 Operating System Implementation Plan

Goal: Implement the approved V1 principles in the existing website with testable calculations and human-controlled data.
Architecture: Separate daily entry, legacy diagnosis and scenario planning. Pure deterministic monthly engine, validated immutable local records, derived content facts.
Tech Stack: React 18, Vite 5, Node test runner; no new runtime dependency.
Spec: docs/superpowers/specs/2026-09-12-v1-design.md

## Global Constraints
- No automatic financial action, AI financial-input writeback, publishing during tests or private inputs sent externally.
- Preserve legacy input key and existing pages. Keep existing cron configuration outside V1.
- All amounts NTD; scenario output is a projection, not a probability or guaranteed income.
